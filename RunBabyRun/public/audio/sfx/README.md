# Zvukové efekty

Zvuky havárií jsou nyní uložené přímo v nadřazeném adresáři `public/audio`:

- `crash004.mp3`
- `crash005.mp3`
- `crash006.mp3`

Používejte názvy bez mezer, malými písmeny a s pomlčkami mezi slovy.
